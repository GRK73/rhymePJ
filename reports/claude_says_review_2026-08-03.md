# `Claude_Says.md` 검토 및 반영 기록

- 검토일: 2026-08-03
- 대상: `Claude_Says.md`와 현재 로컬 코드·자산·테스트
- 원칙: 측정값과 사람 평가가 없는 항목은 제품 완료로 표기하지 않고, 공개 권리가 확인되지 않은 자산은 배포 전에 실패시킨다.

## 결론

검토서의 핵심 진단은 대체로 타당하다. 특히 자동 Pages 배포, 제한 코퍼스의 잘못된 ignore 경로, 외부 조회 기본 실행, 생성 점수의 의미 왜곡, 단일 smoke의 과대 판정, 사람 평가와 다수 인덱스의 부재는 실제 코드·자산과 일치했다. 반면 이미 구현된 정적 검색 builder와 Worker 자체를 미완성으로 되돌릴 이유는 없으므로, 해당 구현은 `기술 완료`로 유지하고 제품 품질·브라우저 성능 판정만 분리했다.

## 수용하여 반영한 항목

| 지적 | 확인 결과 | 반영 |
| --- | --- | --- |
| push 시 무조건 Pages 배포 | 사실 | `deploy.yml`을 수동 실행으로 바꾸고 `npm test`, 제한 코퍼스 차단, 명시적 파일 allowlist, 900MiB 전체·95MiB 단일 파일 게이트를 추가했다. 현재는 allowlist가 없고 제한 코퍼스가 있어 의도적으로 배포 실패 상태다. |
| `.gitignore` 경로 오류 | 사실 | `public/data/corpus/`로 수정했다. 이미 추적된 파일과 원격 이력은 별도 정리 대상이다. |
| 외부 번역·사전 조회가 기본 실행 | 사실 | Google Translate·Wikipedia 직접 호출을 제거하고 사용자 클릭 사전 링크만 남겼다. |
| Pages 하위 경로에서 생성 URL 오류 | 사실 | `document.baseURI` 기준 상대 URL로 변경했다. 정적 generation Worker가 구현되기 전까지 Python fallback은 개발용이다. |
| `novelty`가 코퍼스 비복제성이 아님 | 사실 | `previous_line_distance`로 이름을 바로잡고 `meaning`, `corpus_novelty`는 `null`, `corpus_copy_checked`는 `false`로 반환한다. 파일럿 점수 버전을 명시했다. |
| fluency proxy가 총점에 미반영 | 사실 | 의미·novelty 축이 없는 파일럿 전용 정규화 점수에 반복률 기반 fluency proxy를 반영했다. 제품 통합 점수와는 분리한다. |
| 키워드·음절 제약 누락 | 사실 | 필수 키워드 전체 포함과 요청 음절 범위를 하드 필터로 추가하고 회귀 테스트를 작성했다. |
| smoke 합격 판정 과대 | 사실 | 12개 중 9개 사전 탈락, 요청 4개 중 3개 반환, 현재 계약으로는 반환 3개도 부적합임을 명세·진행현황에 기록했다. 기존 JSON은 역사적 원자료라 수정하지 않았다. |
| 진행현황이 나쁜 지표를 숨김 | 사실 | 상태를 `기술 완료`, `기준 미달`, `평가 부족`, `공개 차단`으로 분리하고 목표·현재·판정을 나란히 기록했다. |
| Cloudflare 잔재와 실제 디렉터리 불일치 | 사실 | 파일럿 보고서를 GitHub Pages/Transformers.js 기준으로 고치고 명세의 `public/js/v2`, `public/workers`, 미구현 Service Worker 상태를 반영했다. |
| XLS-R/MFA/PCA가 미실험인데 확정 사항 | 사실 | v0 범위에서 제외하고 Phase 2·3 사람 평가 이후의 탐색 후보로 강등했다. 64차원은 실험 후보이지 확정값이 아니다. |

## 보류한 항목

| 항목 | 이유와 다음 조치 |
| --- | --- |
| `git rm --cached public/data/corpus/hiphop_corpus.jsonl` | Git index를 변경하고, 이미 원격에 올라갔다면 이력 문제를 해결하지 못한다. 사용자 승인 아래 추적 해제 범위와 원격 이력 재작성 필요 여부를 먼저 결정한다. |
| 실제 GitHub Pages 게시 상태·원격 이력 확인 | 이번 검토는 로컬 저장소 기준이다. 원격 설정과 게시물은 확인하지 않았다. |
| 제한 코퍼스 삭제 | 원본 데이터 보존·권리 판단과 연관된 파괴적 변경이라 수행하지 않았다. 배포 게이트가 먼저 차단한다. |
| `deployment-allowlist.json` 작성 | 현재 `public/`에는 V1 중복 자산과 권리 미확정 데이터가 섞여 있다. 필요한 V2 파일만 골라 artifact를 축소한 뒤 파일 단위로 검토해 작성해야 한다. |
| Backward Rewriter 즉시 ONNX 변환 | 4,096개 예시·80 step 파일럿이며 사람 평가가 0건이다. 먼저 평가셋과 승격 기준을 만들고 합격한 체크포인트만 변환한다. |

## 선택적으로 반영하지 않은 해석

- 정적 검색 shard builder와 Worker는 결정론·hash·oracle 동등성 fixture를 이미 통과했으므로 구현 자체는 `기술 완료`로 유지한다. 다만 실브라우저 p95·메모리·전체 회귀셋이 없으므로 제품 성능은 완료가 아니다.
- 기존 `generation_api_smoke_v0.json`의 `result` 값을 사후 수정하지 않았다. 측정 원자료를 덮어쓰기보다 이 검토서와 명세에서 현재 계약상 실패로 재판정했다.
- 제한 코퍼스를 `.gitignore`에 추가한 것만으로 이미 추적된 파일이 사라졌다고 간주하지 않는다. 배포 게이트와 Git 정리는 서로 별개다.

## 다음 우선순위

1. 제한 코퍼스의 Git 추적·원격 이력 처리 방식을 결정한다.
2. `public/`에서 V1 중복·미참조·권리 미확정 자산을 제외한 최소 Pages artifact를 만든다.
3. 파일 단위 `deployment-allowlist.json`을 검토·확정한다.
4. SQLite-static 다중 시나리오 동등성 및 Chrome cold/warm p50·p95·heap benchmark를 수행한다.
5. 고정 생성 프롬프트 평가셋, 사람 평가 UI·절차, 제품 모델 승격 기준을 만든다.
